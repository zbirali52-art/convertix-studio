## 🚀 Overview

This repository contains the complete open-source web architecture used by **Convertix Studio** to deliver high-converting, mobile-first websites with **₹0 Advance / Pay 100% on Delivery**:

- **Core Agency Landing Page:** Ultra-fast obsidian dark-mode sales engine with interactive AI Receptionist simulator, ROI calculator, and currency toggler.
- **Interactive Showcase Demos:**
  - `demos/dental.html` — Multi-speciality dental clinic with instant WhatsApp slot booking.
  - `demos/cafe.html` — Artisan cafe with dynamic category menu and live cart tray checkout.
  - `demos/interiors.html` — Turnkey interior design studio with real-time BHK layout budget estimator.
- **5 Built-in Open-Source Power Modules (Zero-Subscription Alternatives to Wix & Shopify):**
  - `modules/bookings.html` — Zero-fee calendar booking engine (replaces Wix Bookings & Calendly).
  - `modules/forms.html` — Multi-step lead qualification & quote engine (replaces Typeform & Jotform).
  - `modules/store.html` — Zero-commission e-commerce storefront with WhatsApp checkout (replaces Shopify).
  - `modules/blog.html` — Zero-database static markdown publishing (replaces WordPress & Ghost).
  - `modules/events.html` — Event ticketing & RSVP system with live countdown & Google/iCal sync (replaces Eventbrite & Meetup).

---

## 🛠️ Tech Stack & Zero-Cost Architecture

- **Front-End:** Semantic HTML5, Tailwind CSS via CDN, Vanilla JavaScript (60fps unified `requestAnimationFrame` cursor physics).
- **Typography:** Self-hosted `Plus Jakarta Sans` & `Inter` woff2 fonts (zero external Google font requests).
- **Edge Cloud Hosting:** Netlify Free Global Edge CDN (sub-second load times, free SSL, zero monthly server bills).
- **Lead Capture:** Direct WhatsApp Deep Links + Netlify Forms database fallback.
